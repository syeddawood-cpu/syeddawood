WEB DEVELOPER PORTFOLIO

Files:
- index.html: page content
- style.css: design and responsive styles
- script.js: mobile navigation and project filters

HOW TO USE:
1. Extract the ZIP.
2. Open index.html in a browser to preview.
3. The portfolio name is already set to "Syed Dawood".
4. Replace your.email@example.com and the social links with your own.
5. The 8 project cards are illustrative concepts. Replace them with real projects and add GitHub/live-demo links before publishing.
6. To publish for free, you can use GitHub Pages or Netlify.

Tech stack represented: HTML, CSS, JavaScript, React, Node.js, Express, REST APIs, SQL/PostgreSQL, JWT.
